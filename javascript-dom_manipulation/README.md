# JavaScript - DOM Manipulation

## Description
This project focuses on manipulating the Document Object Model (DOM) using JavaScript. It covers selecting HTML elements, handling events, and updating the style and content of a webpage dynamically without reloading.

## Learning Objectives
By the end of this project, you are expected to be able to explain:
* How to select HTML elements using JavaScript (e.g., `querySelector`, `getElementById`)
* How to update the style of an HTML element
* How to handle events (clicks, mouseover, etc.)
* How to modify the content of an HTML element (`textContent`, `innerHTML`)
* How to fetch data from an API using the `Fetch` API

## Requirements
* **Environment:** Web Browser (Chrome/Firefox) or Ubuntu 20.04 LTS
* **Engine:** `node` (version 14.x)
* **Style:** All files are linted with [semistandard](https://github.com/standard/semistandard)

## File Directory

| File | Description |
| --- | --- |
| `0-script.js` | Script that updates the text color of the `<header>` element to red (#FF0000) |
| `0-main.html` | HTML template to test the color manipulation script |

## Usage
To test the scripts, open the corresponding `.html` file in any modern web browser. The JavaScript file is linked via the `<script>` tag and will execute once the page loads.
