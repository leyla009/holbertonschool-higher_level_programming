# Python - Server Side Rendering

## Description
This project explores the fundamentals of server-side rendering, starting with basic string templating and file manipulation in Python.

## Learning Objectives
* Understand how string templating works in Python.
* Learn to handle complex file operations (reading/writing).
* Implement robust error handling for data edge cases.
